INTEGRATIONS Webhooks & API

When your AI books a job, finishes a call, or escalates an emergency, we can POST it to any URL — a Zapier "Catch Hook", Make, or your own system. From there it goes anywhere.

Every event is signed Dawnpipe-Signature: t=…,v1=… (HMAC-SHA256 over t.body, same shape as Stripe). Verify it if you care who's posting to you.
Read your bookings and calls from anywhere: curl -H "Authorization: Bearer YOUR_KEY" https://dawnpipe.com/v1/bookings — also /v1/calls, /v1/callers/lookup?phone=, /v1/me.
Only if one leaks — anything using the old ones stops working immediately.
